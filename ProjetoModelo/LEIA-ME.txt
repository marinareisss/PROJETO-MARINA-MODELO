PROJETO SALÃO BELLA - PROJETO INTEGRADO

Estrutura: PHP MVC do ProjetoModelo + páginas e estilo da avaliação.

COMO ABRIR NO XAMPP:
1. Extraia a pasta ProjetoModelo para C:\xampp\htdocs\ProjetoModelo.
2. Inicie Apache e MySQL no XAMPP (se o banco for usado).
3. Abra http://localhost/ProjetoModelo/public/site/index.html para visualizar o site da avaliação.
4. Abra http://localhost/ProjetoModelo/ para acessar o fluxo PHP MVC.

As páginas da avaliação estão em public/site; as imagens ficam em public.
O CSS atualizado está em app/views/css/style.css.
